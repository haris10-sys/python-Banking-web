# Python Banking Web Application

🌐 Live Demo:https://python-banking-web-3.onrender.com

This is a banking web application built using Python and Flask.

## Features

- Login
- Check Balance
- Deposit Money
- Withdraw Money
- Fast Cash
- Money Transfer
- Change PIN
- Transaction History
- Account Statement
- CSV Download
- PDF Download
- Email Statement

## Technologies

- Python
- Flask
- HTML
- CSS
- JSON
- ReportLab
- Resend API
- Git & GitHub
